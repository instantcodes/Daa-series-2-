1. Floyd-Warshall Algorithm and its Complexity Analysis

In the All Pairs Shortest Path problem, we find the shortest distance between every pair of vertices in a given weighted, directed graph. Negative edge weights are also allowed. The Floyd-Warshall algorithm is for solving the all pairs shortest path problem. As a result of this algorithm, it will generate a matrix that represents the minimum distance from any node to all other nodes in the graph.

Algorithm FloydWarshall(cost[][], n)
for i = 1 to n do
    for j = 1 to n do
        D⁰[i][j] = cost[i][j]
for k = 1 to n do
    for i = 1 to n do
        for j = 1 to n do
            Dᵏ[i, j] = min{ Dᵏ⁻¹[i, j], Dᵏ⁻¹[i, k] + Dᵏ⁻¹[k, j] }
Return D

  • Time Complexity:
    • Initialization: Two nested loops (i = 1 to n, j = 1 to n) copy the adjacency matrix in Θ(n²) time.
    • Main Triple Loop: Three nested loops (k = 1 to n, i = 1 to n, j = 1 to n) each run n times. The inner comparison and addition min{D[i,j], D[i,k] + D[k,j]} takes constant time O(1).
    • Total Operations: ∑k=1..n ∑i=1..n ∑j=1..n O(1) = n × n × n = Θ(n³).
    • Overall Time Complexity: T(n) = Θ(n²) + Θ(n³) = Θ(n³) (or Θ(|V|³)) in best, average, and worst cases.
  • Space Complexity: Θ(n²) to store the n × n distance matrix D in-place.

2. Steps and Characteristics of Dynamic Programming

Dynamic Programming (DP) is an algorithm design method that can be used when the solution to a problem can be viewed as the result of a sequence of decisions. It is mainly an optimization technique. Whenever a recursive solution has repeated calls for the same inputs, we can optimize it using dynamic programming. DP solves each subproblem just once and stores the result in a table so that it can be repeatedly retrieved when needed again.

Characteristics of Dynamic Programming:

  • Overlapping Subproblems: Subproblems are smaller versions of the original problem. DP combines solutions to subproblems. It is mainly used where the solution of one subproblem is needed repeatedly. The computed solutions are stored in a table so that they don't have to be recomputed; hence, this technique is needed where overlapping subproblems exist.
  • Optimal Substructure: The given problem has the optimal substructure property if the optimal solution of the given problem can be obtained using optimal solutions of its subproblems.

Steps of Dynamic Programming:

  1. Characterize the structure of an optimal solution.
  2. Recursively define the value of an optimal solution.
  3. Compute the value of an optimal solution, typically in a bottom-up manner.
  4. Construct an optimal solution from the computed information.

3. Control Abstraction of Greedy Strategy

For a given problem, there are many possible solutions, but only some solutions satisfy the constraint. They are called feasible solutions. Out of these feasible solutions, one solution will provide the best result. It is called the optimal solution. An optimal solution is a solution which is feasible and gives the best result. For a given problem, there can be more than 1 feasible solution, but only 1 optimal solution.

If a problem requires either a maximum or minimum result, then that problem is called an optimization problem. The strategies used for solving optimization problems are: Greedy Method, Dynamic Programming, and Branch and Bound.

Algorithm Greedy(a, n) // a[1:n] contains n inputs
{
    solution = ϕ
    for i = 1 to n do
    {
        x = select(a)
        if feasible(solution, x) then
            solution = union(solution, x)
    }
    return solution
}
  • Select() function: takes an input from the array a[] and assigns it to x.
  • Feasible(): is a boolean-valued function that determines whether x can be included in the solution.
  • Union(): combines x with the solution.

Analysis of Merge Sort:

Let T(n) be the running time on a problem of size n. In divide-and-conquer method, the running time T(n) can be described as:

T(n) = O(1) if n = 1; and T(n) = aT(n/b) + D(n) + C(n) otherwise, where aT(n/b) means 'a' subproblems each of which is size 1/b of the original. D(n) is the time to divide the problem into subproblems, and C(n) is the time to combine the solutions of the subproblems to obtain the solution of the original problem.

  • Divide: To divide the array into 2 subarrays, computing the mid value q = (p + r)/2 takes O(1) constant time. Therefore, D(n) = O(1).
  • Conquer: Recursively solve 2 subproblems each of size n/2, which takes 2T(n/2).
  • Combine: The merge procedure on an n-element array takes time O(n). Therefore, C(n) = O(n).

T(n) = 2T(n/2) + O(1) + O(n) ⇒ T(n) = 2T(n/2) + n.

Here a = 2, b = 2, logba = log₂2 = 1. Since f(n) = n¹ = Θ(n¹ log⁰n) (k = 1, p = 0), Therefore: T(n) = Θ(n log n).

5. Kruskal's Algorithm and Solved Problems

Spanning Tree: A spanning tree is a subset of an undirected connected graph G = (V, E) which has all of the vertices covered with minimum possible number of edges. A connected graph G can have more than 1 spanning tree. The spanning tree does not have any cycle. Let G = (V, E) be an undirected graph where V is the set of vertices and E is the set of edges. For each edge (u, v) ∈ E, we have a weight w(u, v) specifying the cost to connect u and v. We have to find an acyclic subset T ⊆ E that connects all of the vertices and the total weight w(T) is minimized. Since T is acyclic and connects all of the vertices, it must form a tree called a spanning tree, and the problem of determining the tree T is called the Minimum Spanning Tree problem (MST).

7.         then A ← A ∪ {(u, v)}
8.         UNION(u, v)

6. Fractional Knapsack Problem

We are given n objects and a knapsack (bag) of capacity m. The object i has weight wi and a profit Pi. If a fraction xi is placed into the knapsack, then a profit Pixi is obtained. The objective is to obtain an optimal solution of the knapsack that maximizes the total profit earned. The total weight of all the chosen objects should not exceed m.

Fractional Knapsack problem can be stated as:
Maximize ∑i=1..n Pixi   --- (1)
subject to ∑i=1..n wixi ≤ m   --- (2), and 0 ≤ xi ≤ 1, 1 ≤ i ≤ n   --- (3).
A feasible solution is one that satisfies equations (2) & (3). An optimal solution is a feasible solution that satisfies equation (1).

u = m

1. Approximation Algorithm Theory:

  • Definition: Many optimization problems are NP-Hard, meaning no polynomial-time algorithm is known to find an exact optimal solution. An approximation algorithm runs in polynomial time and finds a feasible, near-optimal solution within a guaranteed factor of the optimal cost.
  • Approximation Ratio ρ(n): If C is the cost of the solution produced by the algorithm and C* is the optimal cost on an input of size n, the algorithm has an approximation ratio ρ(n) if:
    max(C / C*, C* / C) ≤ ρ(n).
    • For a minimization problem (C* ≤ C): C / C* ≤ ρ(n).
    • For a maximization problem (C ≤ C*): C* / C ≤ ρ(n).
  • PTAS & FPTAS: A Polynomial-Time Approximation Scheme (PTAS) achieves a (1 + ε)-approximation in time polynomial in n for any fixed ε > 0. A Fully Polynomial-Time Approximation Scheme (FPTAS) runs in time polynomial in both n and 1/ε.

2. Bin Packing Problem:

  • Problem Statement: Given n items of sizes s₁, s₂, ..., sₙ (where 0 < sᵢ ≤ 1) and bins of capacity 1.0, pack all items into the minimum number of bins.
  • Lower Bound: OPT ≥ ⌈∑i=1..n sᵢ⌉.
  • Approximation Heuristics:
    1. Next Fit (NF — Online): If the current item fits in the currently open bin, place it there; otherwise close that bin and open a new one. Time: O(n). Bound: NF(I) ≤ 2·OPT - 1 (2-approximation).
    2. First Fit (FF — Online): Place the current item into the first open bin (scanning B₁, B₂, ...) that has enough remaining space; if none fits, open a new bin. Time: O(n log n). Bound: FF(I) ≤ ⌈1.7·OPT⌉.
    3. Best Fit (BF — Online): Place the current item into the open bin where it leaves the minimum remaining space (tightest fit); if none fits, open a new bin. Time: O(n log n). Bound: BF(I) ≤ ⌈1.7·OPT⌉.
    4. First Fit Decreasing (FFD — Offline): Sort items in decreasing order of size (s₁ ≥ s₂ ≥ ... ≥ sₙ) and apply First Fit. Time: O(n log n). Bound: FFD(I) ≤ (11/9)·OPT + 4.
  • Example: Items S = {0.2, 0.5, 0.4, 0.7, 0.1, 0.3, 0.8}, Bin Capacity = 1.0.
    • Next Fit (5 Bins): B₁=[0.2, 0.5], B₂=[0.4], B₃=[0.7, 0.1], B₄=[0.3], B₅=[0.8].
    • First Fit (4 Bins): B₁=[0.2, 0.5, 0.1], B₂=[0.4, 0.3], B₃=[0.7], B₄=[0.8].
    • First Fit Decreasing (3 Bins - Optimal): Sorted {0.8, 0.7, 0.5, 0.4, 0.3, 0.2, 0.1} → B₁=[0.8, 0.2], B₂=[0.7, 0.3], B₃=[0.5, 0.4, 0.1].

7B. [OR] Complexity Classes: P, NP, NP-Hard, and NP-Complete

There are 4 complexity classes: 1. Class P, 2. Class NP, 3. Class NP-Hard, 4. Class NP-Complete.

1. Class P: Class P consists of those problems that are solvable in polynomial time. The complexity can be expressed as O(nk), where n is the size of the input and k is a constant.
Example — PATH Problem: Given a directed graph G, determine whether a directed path exists from s to t.
Algorithm: (1) Place a mark on node s and enqueue s into an empty queue. (2) Repeat Step 3 until the queue is empty. (3) Dequeue the first element, mark all unmarked connected neighbors of it, and enqueue those into the queue. (4) If t is marked then accept, otherwise reject.

2. Class NP: Suppose some problems have no polynomial-time solution, but we can verify solutions to these problems in polynomial time. Such problems are called NP problems. Class NP is the class of problems that have a polynomial-time verification algorithm.
Example — Hamiltonian Path Problem (HAM-PATH): A Hamiltonian path in a directed graph G is a directed path that goes through each node exactly once. There is no polynomial-time solution to find a Hamiltonian path from s to t in a given graph. HAM-PATH is to test whether a graph contains a Hamiltonian path connecting two specified nodes.
