1. Floyd-Warshall Algorithm and its Complexity Analysis

In All Pairs Shortest Path problem, we find the shortest distance between every pair of vertices in a given weighted, directed graph [span_34](start_span)[span_34](end_span)[span_35](start_span)[span_35](end_span). Negative edge weights are also allowed [span_36](start_span)[span_36](end_span)[span_37](start_span)[span_37](end_span). The Floyd-Warshall algorithm is for solving the all pairs shortest path problem [span_38](start_span)[span_38](end_span)[span_39](start_span)[span_39](end_span). As a result of this algorithm, it will generate a matrix that represents the minimum distance from any node to all other nodes in the graph [span_40](start_span)[span_40](end_span)[span_41](start_span)[span_41](end_span).

Algorithm FloydWarshall(cost[][], n)
for i = 1 to n do
    for j = 1 to n do
        D⁰[i][j] = cost[i][j]
for k = 1 to n do
    for i = 1 to n do
        for j = 1 to n do
            Dᵏ[i, j] = min{ Dᵏ⁻¹[i, j], Dᵏ⁻¹[i, k] + Dᵏ⁻¹[k, j] }
Return D
Added Missing Part — Complexity Analysis (KTU Syllabus)
  • Time Complexity:
    • Initialization Loop: Two nested for loops copy cost[i][j] into D⁰[i][j] in Θ(n²) time.
    • Triple Nested Loop: Three nested for loops (k = 1..n, i = 1..n, j = 1..n) each iterate n times. The inner update min{D[i,j], D[i,k] + D[k,j]} takes constant time O(1).
    • Total Time: T(n) = Θ(n²) + ∑k=1..n ∑i=1..n ∑j=1..n O(1) = Θ(n³) (or Θ(|V|³)) in best, average, and worst cases.
  • Space Complexity: Θ(n²) auxiliary space to store the n × n distance matrix D.

2. Steps and Characteristics of Dynamic Programming

Dynamic Programming (DP) is an algorithm design method that can be used when the solution to a problem can be viewed as the result of a sequence of decisions [span_42](start_span)[span_42](end_span)[span_43](start_span)[span_43](end_span). It is mainly an optimization technique [span_44](start_span)[span_44](end_span)[span_45](start_span)[span_45](end_span). Whenever a recursive solution has repeated calls for the same inputs, we can optimize it using dynamic programming [span_46](start_span)[span_46](end_span)[span_47](start_span)[span_47](end_span). DP solves each subproblem just once and stores the result in a table so that it can be repeatedly retrieved when needed again [span_48](start_span)[span_48](end_span)[span_49](start_span)[span_49](end_span).

Characteristics of DP:

  • Overlapping Subproblems: Subproblems are smaller versions of the original problem [span_50](start_span)[span_50](end_span)[span_51](start_span)[span_51](end_span). DP combines solutions to subproblems [span_52](start_span)[span_52](end_span)[span_53](start_span)[span_53](end_span). It is mainly used where the solution of one subproblem is needed repeatedly [span_54](start_span)[span_54](end_span)[span_55](start_span)[span_55](end_span). The computed solutions are stored in a table so that they don't have to be recomputed; hence, this technique is needed where overlapping subproblems exist [span_56](start_span)[span_56](end_span)[span_57](start_span)[span_57](end_span).
  • Optimal Substructure: The given problem has optimal substructure property if the optimal solution of the given problem can be obtained using optimal solutions of its subproblems [span_58](start_span)[span_58](end_span)[span_59](start_span)[span_59](end_span).

Steps of Dynamic Programming:

  1. Characterize the structure of an optimal solution [span_60](start_span)[span_60](end_span)[span_61](start_span)[span_61](end_span).
  2. Recursively define the value of an optimal solution [span_62](start_span)[span_62](end_span)[span_63](start_span)[span_63](end_span).
  3. Compute the value of an optimal solution, typically in a bottom-up manner [span_64](start_span)[span_64](end_span)[span_65](start_span)[span_65](end_span).
  4. Construct an optimal solution from the computed information [span_66](start_span)[span_66](end_span)[span_67](start_span)[span_67](end_span).

3. Control Abstraction of Greedy Strategy

For a given problem, there are many possible solutions, but only some solutions satisfy the constraint; they are called feasible solutions [span_68](start_span)[span_68](end_span)[span_69](start_span)[span_69](end_span). Out of these feasible solutions, one solution will provide the best result; it is called the optimal solution [span_70](start_span)[span_70](end_span)[span_71](start_span)[span_71](end_span). An optimal solution is a solution which is feasible and gives the best result [span_72](start_span)[span_72](end_span)[span_73](start_span)[span_73](end_span). For a given problem, there can be more than 1 feasible solution, but only 1 optimal solution [span_74](start_span)[span_74](end_span)[span_75](start_span)[span_75](end_span).

If a problem requires either maximum/minimum result, then that problem is called an optimization problem [span_76](start_span)[span_76](end_span)[span_77](start_span)[span_77](end_span). The strategies used for solving optimization problems are: Greedy Method, Dynamic Programming, and Branch and Bound [span_78](start_span)[span_78](end_span)[span_79](start_span)[span_79](end_span).

Algorithm Greedy(a, n) // a[1:n] contains n inputs
{
    solution = ϕ
    for i = 1 to n do
    {
        x = select(a)
        if feasible(solution, x) then
            solution = union(solution, x)
    }
    return solution
}

  • Feasible(): is a boolean-valued function that determines whether x can be included in the solution [span_82](start_span)[span_82](end_span)[span_83](start_span)[span_83](end_span).
  • Union(): combines x with the solution [span_84](start_span)[span_84](end_span)[span_85](start_span)[span_85](end_span).

Spanning Tree: Spanning tree is a subset of an undirected connected graph G = (V, E) which has all of the vertices covered with minimum possible number of edges [span_102](start_span)[span_102](end_span)[span_103](start_span)[span_103](end_span). Let G = (V, E) be an undirected graph where V is the set of vertices and E is the set of edges; for each edge (u, v) ∈ E, we have a weight w(u, v) specifying the cost to connect u and v [span_106](start_span)[span_106](end_span)[span_107](start_span)[span_107](end_span). We have to find an acyclic subset T ⊆ E that connects all of the vertices and the total weight w(T) is minimized [span_108](start_span)[span_108](end_span)[span_109](start_span)[span_109](end_span). This is called the Minimum Spanning Tree problem (MST) [span_110](start_span)[span_110](end_span)[span_111](start_span)[span_111](end_span).

MST_KRUSKAL(G, w)
1. A ← ϕ
2. for each vertex v ∈ V[G]
3.     do MAKE-SET(v)
4. Sort the edges of E into non-decreasing order by weight w
5. for each edge (u, v) ∈ E, taken in non-decreasing order by weight
6.     do if FIND-SET(u) ≠ FIND-SET(v)
7.         then A ← A ∪ {(u, v)}
8.         UNION(u, v)
9. return A

1. Approximation Algorithm Theory:

  • Purpose: Find near-optimal solutions in polynomial time for NP-Hard optimization problems.
  • Approximation Ratio ρ(n): If C is the algorithm's solution cost and C* is the optimal cost, max(C/C*, C*/C) ≤ ρ(n). (For minimization: C/C* ≤ ρ(n); for maximization: C*/C ≤ ρ(n)).
  • PTAS vs. FPTAS: A PTAS achieves a (1 + ε)-approximation in time polynomial in n; an FPTAS runs in time polynomial in both n and 1/ε.

2. Bin Packing Problem & Heuristics:

  • Given n items of sizes s₁, ..., sₙ ∈ (0, 1], pack them into the minimum number of unit-capacity (1.0) bins. Lower bound: OPT ≥ ⌈∑ sᵢ⌉.
  • Next Fit (NF): Check only current bin; if it doesn't fit, close it and open a new bin. Bound: NF(I) ≤ 2·OPT - 1.
  • First Fit (FF): Place item in the first bin (scanning B₁, B₂, ...) where it fits. Bound: FF(I) ≤ ⌈1.7·OPT⌉.
  • Best Fit (BF): Place item in the bin that leaves the least remaining empty space. Bound: BF(I) ≤ ⌈1.7·OPT⌉.
  • First Fit Decreasing (FFD): Sort items in decreasing order, then apply First Fit. Bound: FFD(I) ≤ (11/9)·OPT + 4.
